# Validação manual — exportação PLCopen XML

**Objetivo:** conferir se um `.xml` exportado pelo menu **Baixar → PLCopen XML**
abre em um editor que aceite PLCopen TC6 (ex.: Beremiz, OpenPLC Editor).

**Procedimento sugerido:**

1. No LadderFlow, montar ou carregar um diagrama simples (ex.: fixture IO_ESPELHO).
2. Baixar **PLCopen XML (.xml)**.
3. Importar ou abrir o arquivo no editor externo escolhido.
4. Registrar aqui: software e versão, diagrama usado, resultado (abriu / redesenhou /
   erros) e data.

**Nota:** o XSD da PLCopen **não** é copiado para o repositório (Regra 4 do
`CLAUDE.md`). Se for usar o XSD, mantenha-o só na máquina de teste.
